# Título:
Pulverizador Elétrico e Manual

# Definição da categoria:
Nó de fonte de energia, filho de [[Pulverizador]]. Este é um eixo que nunca pode ficar ambíguo: os 3 nós possíveis (Manual / Elétrico / Elétrico e Manual) são sempre distintos entre si, nunca fundidos nem usados um pelo outro. Um produto liga-se a este nó específico apenas quando os dados confirmam dois modos de acionamento reais e independentes (um elétrico via bateria, outro manual via bombeamento físico).
